# NewBin

NewBin is a secure, privacy-focused pastebin alternative that respects your freedom.

## 🚀 Features

- 🔒 AES encryption
- 🕒 Customizable expiration times
- 🔥 Burn after reading option
- 🎨 Syntax highlighting for various programming languages
- 🌓 Dark and light mode support
- 📱 Responsive design for all devices

## 🛡️ Privacy & Security

At NewBin, we believe in:

- **Free Software**: Not just free in price, but in privacy and user freedom.
- **AES Encryption**: Your data is encrypted before it leaves your device.
- **No Tracking**: We don't track you or your data.
- **Open Source**: Our code is open for review and contribution.

## 🚀 Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/notguyn/newbin.git
   ```

2. Install dependencies:
   ```
   cd newbin
   bun install
   ```

3. Run the development server:
   ```
   bun run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
